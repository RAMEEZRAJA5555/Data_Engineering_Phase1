# Grid

## Definition

A **grid** is a set of horizontal and/or vertical lines displayed across the graph.

Grid lines help us read and compare values more easily.

## Example

```python
plt.grid()
```

This displays grid lines on the graph.

## Purpose

* Makes values easier to read.
* Helps compare data points with the axes.
* Improves graph readability.

## Remember

> **Grid = lines that help us read values on the graph.**
