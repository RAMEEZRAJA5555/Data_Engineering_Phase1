# Markers

## Definition

**Markers** are symbols used to show individual data points on a graph.

For example, a data point can be shown as a circle, square, triangle, or another symbol.

## Example

```python
plt.plot([1, 2, 3], [10, 20, 15], marker="o")
```

Here, `"o"` represents a circular marker.

## Purpose

Markers make individual data points easier to see.

## Remember

> **Marker = symbol used to display individual data points.**
