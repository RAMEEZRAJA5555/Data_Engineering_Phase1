# Legend

## Definition

A **legend** explains what different lines, bars, markers, or other elements in a graph represent.

It is especially useful when a graph contains multiple datasets.

## Example

```python
plt.plot(days, temperature1, label="City A")
plt.plot(days, temperature2, label="City B")

plt.legend()
```

The legend tells us which line belongs to **City A** and which belongs to **City B**.

## Purpose

A legend helps the viewer identify different datasets in a graph.

## Remember

> **Legend = explains what different graph elements represent.**
