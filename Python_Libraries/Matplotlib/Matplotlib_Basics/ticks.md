# Ticks

## Definition

**Ticks** are the small marks and values shown along the X-axis and Y-axis.

They help us understand the numerical or categorical positions on a graph.

## Example

If the Y-axis shows:

```text
0
20
40
60
80
100
```

These values are **ticks**.

## Purpose

Ticks help the viewer read and understand the values on the graph.

## Remember

> **Ticks = marks and values used to read the axes.**
