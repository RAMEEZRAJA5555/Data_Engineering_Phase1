# X-Axis and Y-Axis

## Definition

The **X-axis** and **Y-axis** are the two main axes used to represent data in a graph.

### X-Axis

The X-axis is the **horizontal line** in a graph.

It usually represents the input, category, or independent variable.

### Y-Axis

The Y-axis is the **vertical line** in a graph.

It usually represents the value, measurement, or dependent variable.

## Example

If we plot:

* Days on the X-axis
* Temperature on the Y-axis

Then:

```text
X-axis → Days
Y-axis → Temperature
```

## Remember

> **X-axis = horizontal**
> **Y-axis = vertical**
