# Colors

## Definition

**Colors** can be used in Matplotlib to change the appearance of lines, bars, markers, and other graph elements.

## Example

```python
plt.plot([1, 2, 3], [10, 20, 15], color="red")
```

Here, the line is displayed in red.

## Purpose

Colors can:

* Make graphs easier to understand.
* Differentiate between datasets.
* Highlight important information.

## Important

Colors should be used carefully so that the graph remains clear and easy to read.

## Remember

> **Colors = control the visual color of graph elements.**
